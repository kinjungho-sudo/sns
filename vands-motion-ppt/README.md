# 밴스의원 부산점 · GEO 제안 (3장 모션 발표)

재한님이 말씀하신 3장 구성입니다. 장마다 약 30초짜리 광고 영상처럼 한 편이 재생되고, 중요한 내용만 큰 글씨와 실제 화면으로 보여 줍니다.

| 장 | 길이 | 흐름 |
|---|---|---|
| 1부 · 진단 | 34초 | 실제 홈페이지 위로 AI 스캔 → 거대한 숫자 65 · 19 · 96이 하나씩 화면을 채운 뒤 제자리로 → 거대한 "4"와 과제 네 줄 → "항목별로 고치고 같은 질문으로 재측정" |
| 2부 · 이번 제공 범위 | 32초 | 시안 화면이 화면 가득 → 오른쪽 카드로 줄어들며 왼쪽에 83 생성(기존과 비교하지 않음 표기) → 시술 안내·진료시간 화면 확대 → 네 단계 필름 |
| 3부 · 향후 로드맵 | 33초 | 가상 예시 표시 → SNS 콘텐츠(휴대폰 피드 + 바뀌는 큰 단어) → 업무 도우미(질문·답 타이핑) → 보이스 차트(파형 → 차트 초안) → 마무리 |

## 여는 법과 조작
`index.html`을 크롬에서 엽니다. 화면에는 버튼이 없고 키보드로만 조작합니다.

| 키 | 동작 |
|---|---|
| 클릭 · `Space` | 시작 / 재생 · 일시정지 |
| `→` `←` (PageDown / PageUp) | 다음 · 이전 장 |
| `1` `2` `3` | 장 바로 가기 |
| `.` `,` | 장 안에서 다음 · 이전 장면으로 건너뛰기 |
| `R` | 이 장 처음부터 |
| `M` · `C` · `F` · `?` | 소리 끄기 · 자막 켜고 끄기 · 전체 화면 · 단축키 도움말 |

- **화면 표시:** 오른쪽 위 쪽수와 맨 아래 아주 얇은 진행선만 보입니다. 마우스를 2.5초 움직이지 않으면 쪽수와 커서도 숨습니다.
- **모션 줄이기:** 시스템의 모션 줄이기 설정이면 장을 열자마자 완성된 화면을 보여 줍니다.

## 소리
- **배경음악:** `assets/audio/bgm.m4a`. 코드로 직접 합성한 잔잔한 앰비언트 곡이라 저작권 문제가 없습니다. 53초 단위로 이음매 없이 반복되고, 내레이션이 나올 때는 더 작아집니다. 다시 만들려면 `node tools/make-bgm.mjs`.
- **내레이션 (Typecast)**
  - 대본은 `narration.js`에 있습니다. 지금은 대본이 자막으로 나옵니다.
  - 음성을 넣으려면 `TYPECAST_API_KEY`를 환경 비밀값으로 넣고 `node tools/narrate.mjs`를 실행합니다(선택: `TYPECAST_VOICE_ID`).
  - 실행하면 `assets/audio/narration/slide-1~3.m4a`와 `timing.js`가 생기고, 발표 화면이 실제 음성 시각에 맞춰 음성과 자막을 함께 냅니다.
  - 작업 환경에서는 키가 없고 api.typecast.ai 접속이 막혀 있어 음성은 아직 만들지 못했습니다.

## 검사
`node tools/check.mjs` → `review/`에 장면별 스크린샷(1920×1080, 1366×768)과 `check-report.txt`가 저장됩니다. 마지막 결과는 12개 항목 모두 통과입니다.
- 화면에 조작 버튼·하단바·레일이 없음
- 오프라인에서 폰트 로드, 콘솔 오류 0건
- Space·화살표·숫자·`.`·`C`·`?` 키 동작
- 3장 모든 장면에서 글자가 화면 밖으로 나가지 않음
- 대본 19줄 자막이 제 시각에 나옴
- 모션 줄이기 대응
