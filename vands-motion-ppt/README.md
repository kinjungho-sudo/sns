# 밴스의원 부산점 · HTML + 모션그래픽 발표 (오프닝 + 1–3부)

1. ZIP 파일 전체를 한 폴더에 압축 해제합니다.
2. 폴더 안의 index.html을 Chrome 또는 Edge에서 엽니다.
3. 상단에서 1부·2부·3부를 선택하거나 재생 버튼을 누릅니다.

서버나 설치 없이 실행됩니다. 원문 웹 링크만 인터넷이 필요하며, 발표 화면·보고서 PDF·연출 메모는 로컬에 포함했습니다.

- 오프닝 1장(15초 모션그래픽) + 1부 8장 / 2부 6장 / 3부 4장(시연 영상 3편 + 피부과 SNS 참고 1장), 총 19장.
- Space: 재생·일시정지. ←/→: 단계 이동. PageUp/PageDown: 장면 이동.
- Home/End: 처음/마지막. F: 전체 화면. 진행 슬라이더와 터치 스와이프 지원.
- 2부 바로 열기: index.html#10 / 3부: index.html#16 (오프닝이 #1).
- 일반 모드 연속 재생 계산값: 오프닝 15초 + 21장 × 약 7.3초. 프레임 처리에 따라 소폭 차이가 있습니다.
- 시스템 모션 줄이기 설정을 따릅니다. 실제 마이크 녹음은 하지 않습니다.

이 파일은 기존 56.9MB 개발·검증 묶음에서 실행에 사용하지 않는 스토리보드 원본, 보고서 렌더링 이미지, 전체 화면 검증 캡처, 중복 자료를 제외한 배포본입니다. 사용 중인 이미지·코드·원문 PDF는 원본 그대로여서 화질 저하가 없습니다.

검증 요약은 verification 폴더에 있습니다. 두 해상도 21개 장면의 원본/경량본 비교와 실행 검증 결과는 lite-validation.json을 참조하세요. 원본 개발·검증 자료는 기존 통합본에 보존했습니다.

83/100은 신규 시안의 홈페이지 AI 검색 준비도이며 기존 65점과 전후 성과 비교하지 않습니다. 3부는 향후 도입 가상 예시·별도 협의 옵션입니다. 견적, CRM 연계, 외부 배포, MP4 출력은 포함하지 않았습니다.

- 기존 자체 검증 기록은 `verification-original/`에 그대로 두었습니다.

## 3부 개편 (2026-11-03, 2차)
텍스트뿐이던 3부 7장을 시연 영상 중심의 4장으로 바꿨습니다. 모두 “향후 도입 가상 예시 · 별도 협의 옵션”입니다.
- **#16 SNS 콘텐츠 자동화 시연 (14초, `motion/sns.html`)**

  - 많이 쓰는 형식: 카드뉴스·숏폼·다국어.

  - 자동화해도 지킬 의료광고 기준: 치료 경험담 제한(의료법 제56조 제2항), 후기 조건 할인(제27조 제3항), 일평균 이용자 10만 이상 SNS의 사전심의.

- **#18 내부 지식 보조 시연 (10초, `motion/knowledge.html`)**
  - 흐름: 직원 질문 → 공식 병원 정보에서 출처와 함께 답.
  - 답의 내용은 고객 전달 시안의 진료시간 문구만 사용했습니다.
  - 비슷한 제품: Notion AI, ChatGPT 프로젝트, Glean.
