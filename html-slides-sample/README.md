# HTML + 모션그래픽 슬라이드 · 3장 샘플

`index.html`을 크롬에서 더블클릭하면 열립니다. 빌드도 서버도 필요 없습니다. 문구와 수치는 전부 `content.json`에 있고, 화면의 숫자는 **예시 데이터**입니다 (`"dummy": true`라서 각 장 하단에 "예시 데이터"가 표시됩니다).

## 주제 바꾸는 법
1. `content.json`의 문구와 수치를 고칩니다. 제목의 강조어는 `*이렇게*` 감싸고, 실제 데이터라면 `"dummy": false`로 바꿉니다.
2. `node tools/sync-content.mjs`를 실행합니다. 더블클릭으로 열 때 쓰는 사본(`js/content.js`)을 맞추는 단계입니다.
3. 새로고침합니다. 합계와 증감률은 분기 값에서 자동으로 계산되므로, 해설 문장만 새 수치에 맞게 다시 읽어 보세요.

## 영상 다시 만드는 법
1. 처음 한 번만 `npm install`을 실행합니다 (Playwright·GSAP·Chart.js, ffmpeg 필요).
2. `node tools/render-video.mjs`를 실행하면 `motion/promo.html`이 `assets/video/promo.mp4`와 `promo-poster.jpg`로 렌더됩니다 (약 1분).
3. 장면은 `motion/promo.html`의 GSAP 타임라인에서 고칩니다. 키워드, 숫자, 4단계, 메시지는 `content.json`에서 가져옵니다.

## 조작
| 동작 | 방법 |
|---|---|
| 장 이동 | ←/→, PageUp/PageDown, 하단 화살표, 좌측 번호, 좌우 스와이프 |
| 바로 가기 | 주소 끝 `#1` `#2` `#3` (새로고침해도 유지) |
| 전체화면 | 상단 ⛶ 또는 `F` |
| 편집 모드 | `E`로 켜고 글자를 클릭해 고친 뒤 **content.json 저장**을 누르면, 받은 파일로 `content.json`을 바꾸고 2번 단계를 실행 |

## 검사
`node tools/check.mjs`를 실행하면 `review/`에 1920×1080과 1366×768 스크린샷, 그리고 `check-report.txt`가 저장됩니다. 마지막 실행 결과는 경고 1건을 빼고 모두 통과했습니다.
- **오프라인 file://** (외부 요청 전부 차단): 폰트 400·700·800 로드, 차트 표시(로컬 Chart.js 사본), 영상 재생. 콘솔 오류는 차단된 CDN 요청 1건뿐입니다.
- **넘침·겹침**: 3장 × 2해상도 모두 없음.
- **연도 버튼 3개**: 차트·큰 숫자·해설이 함께 바뀝니다. 큰 숫자는 원자료 합계와 일치합니다 (4,330 / 6,280 / 8,250건).
- **장 3 영상**: 진입하면 무음 자동 재생, 떠나면 정지.
- **콘솔 오류**: 온라인 조건에서 0건.
- **content.json 반영**: 문구 수정이 서버로 열 때 바로 반영되고, sync 후 더블클릭으로 열 때도 반영됩니다.
- **동작 줄이기**: 전환·카운트업·차트 애니메이션이 0입니다.
- **영상 사양**: H.264 · 1920×1080 · 30fps · 15.00초 · 오디오 없음. 프레임 간 밝기가 10% 이상 튀는 곳은 0곳입니다.

## 설계 문서와 다르거나 직접 정한 점
- **모션 도구**: Remotion이 설치돼 있지 않아 GSAP HTML(`motion/promo.html`)로 만들었고, 그것을 프레임 단위로 렌더해 mp4를 만듭니다.
- **더블클릭과 content.json**: 크롬은 file://에서 JSON 읽기를 막습니다. 그래서 더블클릭으로 열 때는 `js/content.js` 사본을 읽고, 서버로 열 때는 `content.json`을 직접 읽습니다.
- **Chart.js 사본**: cdnjs에서 받지 못하면 `js/vendor/chart.umd.js`(v4.4.1)를 씁니다. 그래서 인터넷 없이도 차트가 나옵니다.
- **검사 브라우저와 H.264**: Playwright의 Chromium은 H.264를 재생하지 못합니다. 재생 동작은 같은 영상의 VP9 임시 사본으로 검사했습니다 (결과물은 H.264). `review/`의 장 3 스크린샷에 포스터만 보이는 것도 이 때문입니다. 실제 크롬에서 H.264 재생은 이 환경에서 확인하지 못했습니다.
- **cdnjs 주소**: 작업 환경에서 cdnjs 접속이 막혀 있어 `chart.umd.min.js` 주소를 직접 열어 보지 못했습니다. 검사에서는 그 주소를 로컬 사본으로 대신했습니다.
- **글자 크기**: 1600px 기준 수치를 1920px 무대에 맞춰 1.2배 했습니다 (제목 56px, 큰 숫자 92px 등).
- **차트 축**: 모든 해의 최대값으로 고정해, 연도를 바꾸면 막대 높이로 변화가 보입니다.
- **대비 경고**: `--muted`(#787983)는 흰 배경에서 4.32:1로, 작은 글자 기준 4.5:1에 조금 못 미칩니다. 문서가 정한 토큰이라 그대로 두었습니다. `#737480`으로 바꾸면 4.63:1입니다.
- **버튼 글자**: 흰 글자/강조색 대비가 4.42:1이라, 버튼 글자를 굵은 20px(큰 글자 기준 3:1)로 정했습니다.
- **동작 줄이기와 영상**: 이 설정이면 장 3 영상을 자동 재생하지 않고, ▶ 재생을 눌러야 합니다.
- **레퍼런스**: 설계 문서의 실측 토큰과 구조만 사용했습니다. 레퍼런스 사이트와 영상은 열지 않았고, 코드·이미지·문구도 가져오지 않았습니다.
