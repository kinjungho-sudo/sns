# 밴스의원 부산점 AI 검색(GEO) 제안 · 모션 슬라이드

`index.html`을 크롬에서 더블클릭하면 열립니다. 디자인과 엔진은 `design-doc-deck`(설계 문서의 HTML 모션 슬라이드 방식)과 같고, 문구와 수치는 전부 `content.json`에 있습니다.

## 내용 출처
- **진단 수치**: DrGEO 진단 보고서 (2026-11-02 측정). Gemini 5/18, Claude 5/18, ChatGPT는 수집 실패로 제외해 10/36(28%)입니다. 관찰한 병원 58곳 중 5위(전체 시장 순위 아님), 홈페이지 준비도 47/100(자체 규칙 점수).
- **개선 후보·진행 방식·홈페이지 방향·제외 범위**: Second Brain AX컨설팅 보관함의 「벤스의원」, 「2026-11-03 밴스 GEO 감사와 개선 결정」 기록.
- **가격·계약**: 미정이라 넣지 않았고, "견적서로 별도 안내"로 표시했습니다.

## 고치는 법
1. `content.json`을 고칩니다. 장을 더하거나 순서를 바꾸면 레일과 쪽수가 따라옵니다.
2. `node tools/sync-content.mjs`를 실행합니다 (더블클릭용 사본 갱신).
3. 영상 문구를 바꿨다면 `node tools/render-video.mjs`를 실행합니다 (`npm install` 필요).
