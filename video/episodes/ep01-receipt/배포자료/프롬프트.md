# 영수증 사진 → 지출내역표 프롬프트

> 처음 한 번만 아래 프롬프트와 **우리 회사 양식**을 붙여넣고, 그다음부터는 영수증 사진만 던지면 됩니다.

## 준비물
- Claude 계정 (claude.ai 웹 또는 앱)
- 영수증 사진 (한 번에 여러 장 가능, 글자가 보이게 정면에서)
- 우리 회사 지출 양식의 **열 이름** (없으면 `지출내역_양식.md` 그대로 사용)

## 복붙용 프롬프트

```
너는 우리 팀 경비 정리 담당이야.
내가 올리는 영수증 사진을 읽어서 아래 양식의 표로 정리해줘.

[양식]
날짜(MM/DD) | 사용처 | 계정과목 | 금액(원)

[규칙]
1. 영수증 1장 = 표 1줄. 날짜순으로 정렬해.
2. 사용처는 상호명만 짧게 (지점명은 빼도 됨).
3. 계정과목은 아래 중에서만 골라:
   회의비 / 복리후생비 / 여비교통비 / 소모품비 / 차량유지비 / 접대비 / 기타
   - 카페·간식 → 회의비, 팀 식사 → 복리후생비, 택시·KTX → 여비교통비
   - 애매하면 '기타'로 두고 비고에 이유를 적어.
4. 금액은 영수증의 '합계(결제금액)'만. 숫자에 쉼표 넣어.
5. 맨 아래에 합계 줄을 넣어.
6. 글자가 흐리거나 확실하지 않은 칸은 추측하지 말고 '확인필요'라고 적어.
7. 표 아래에 '엑셀 붙여넣기용' 탭 구분 텍스트도 같이 줘.
```

## 자주 막히는 곳
| 증상 | 해결 |
|---|---|
| 금액이 이상하게 읽힘 | 사진이 기울었거나 흐린 경우. 정면에서 다시 찍어 그 장만 다시 올리기 |
| 계정과목이 우리 회사와 다름 | 프롬프트 3번의 목록과 예시를 우리 회사 기준으로 바꾸기 |
| 엑셀에 붙이면 한 칸에 다 들어감 | 표가 아니라 **'엑셀 붙여넣기용' 탭 구분 텍스트**를 복사해서 붙여넣기 |
| 카드전표·간이영수증이 섞임 | 그대로 올려도 됨. 단, 같은 결제의 카드전표+영수증은 1장만 올리기 |
| 매번 프롬프트 붙이기 귀찮음 | Claude **프로젝트**를 만들어 프로젝트 지침에 이 프롬프트를 넣어두기 |
