# EP.2 지출결의서 자동 작성 — 프롬프트

> 출처: 무료 자료 배포 페이지(노션) EP.2 · 지출결의서 자동 작성
> 양식 파일(`EP02_지출결의서_양식.xlsx`)은 노션 페이지에서 내려받으세요.

**Before →** 월말마다 뒤섞여 쌓이는 영수증 뭉치
**After →** 영수증 사진만 넣으면 회사 양식 그대로 채워지는 지출결의서

## 순서
1. 영수증 사진(여러 장 OK)과 '지출결의서 양식'을 Claude(또는 ChatGPT)에 올린다.
2. 프롬프트를 복사해 붙여넣는다.
3. 완성된 지출결의서에서 합계·날짜를 한 번 확인한다.

## 한번에 완성하는 프롬프트
```
너는 회계·총무 담당자의 지출결의서 작성을 돕는 도우미야.

[해야 할 일]
1. 첨부한 영수증 사진들에서 다음 항목을 읽어줘: 지출일자, 상호(가맹점), 금액, 결제수단.
2. 각 지출을 알맞은 계정과목으로 분류해줘(소모품비·회의비·교통비·식대·접대비·통신비·도서인쇄비·지급수수료·여비교통비·복리후생비).
3. 함께 첨부한 '지출결의서 양식'의 제목·항목·표 구조를 그대로 유지한 채 값만 채워 완성해줘. 열을 추가·삭제하거나 순서를 바꾸지 마. (양식이 없으면 표를 새로 만들지 말고 '지출결의서 양식 파일을 첨부해 주세요'라고 요청한 뒤 멈춰)
4. 금액·날짜는 영수증 숫자를 그대로 옮기고 임의로 바꾸지 마. 안 보이거나 불확실한 값은 '확인 필요'로 표시해.
5. 금액 합계를 계산해 넣고, 첨부 양식의 시트·제목·항목·표 구조를 그대로 유지한 완성 .xlsx 파일 하나만 반환해. 불확실한 값은 해당 셀에 '확인 필요'라고 적고, 파일 외 설명·별도 목록·새 시트는 만들지 마.
```
