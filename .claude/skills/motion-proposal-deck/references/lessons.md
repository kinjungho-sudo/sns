## 진행 방식
- 크레딧이 드는 외부 생성(vidIQ 음성 등)은 쓰기 전에 비용을 한 줄로 알린다. 끝나면 쓴 양을 보고.
- 사용자가 API 키를 채팅에 붙이게 하지 않는다. 환경 설정(Network secrets/환경변수)으로 안내.
- 직접 들을 수 없는 소리는 "들어 보시고 말씀해 주세요"라고 솔직히 쓴다.
- 보고는 한국어, 무엇을 바꿨는지·어디서 보이는지·못 한 것과 이유.
