# 모션 제안서 덱 (HTML + 모션그래픽 PPT)

완성 사례: `vands-motion-ppt/` (밴스의원 부산점 제안서, https://sns-orpin.vercel.app).
이 폴더가 곧 템플릿이다. 엔진(재생·자막·소리·확대·모바일·검사)은 다 풀려 있으니 **내용만 바꾼다**.

결과물 = Vercel에 배포된 주소 + 브랜치에 커밋된 소스. 계획서·시안 이미지는 결과물이 아니다.

## 처음 대화에서 정할 것 (모르면 이 기본값)
- **구성**: 3부 구조. 1부 진단(현황·문제) → 2부 이번 제공 범위(해결책·시안) → 3부 참고 예시(만들 수 있는 것, "제안 범위 아님"으로 표기) → 마지막 "감사합니다".
- **분량**: 부마다 표지 1장 + 핵심 장면 3~4장. 전체 15장 안팎, 1.25배속으로 약 3분.
- **테마**: noir(블랙·샴페인 골드). 병원·뷰티는 보라 그라데이션 금지(사용자가 싫어함).
- **목소리**: vidIQ 음성(ElevenLabs, 연결된 커넥터라 바로 됨, 크레딧 소모 → 사용 전 한 줄 알림). 타입캐스트는 환경에 `TYPECAST_API_KEY`와 `api.typecast.ai` 네트워크 허용이 있어야 함.

## 만드는 순서
1. `bash .claude/skills/motion-proposal-deck/scripts/new-deck.sh <폴더>` 로 복사. 원본 자료(PDF·이미지)는 `<폴더>/sources/`, 화면 캡처는 `assets/`.
2. **내용 교체** (자세한 구조: `references/engine.md`)
   - 1부 장면: `app.js` 맨 위 `scenes` 배열 / 2부: `next-scenes.js` / 3부 시연: `roadmap-scenes.js`
   - 부 표지 큰 글씨: `COVER`, 남길 장면: `KEEP`, 내레이션 대본: `VO`(키=`부-순서`, 장면에 `vokey`로 고정 가능)
   - 상단 제목: `index.html`의 `.brand`, 공유 카드 문구·주소: `index.html` 메타 + `tools/og/card.html`
3. **시연 영상**(3부 등): `motion/<이름>.html`(GSAP 타임라인, `motionKit.start(tl, 초)`) → `python3 tools/make-themes.py` → `node tools/render-video.mjs [--theme noir] <이름>`. 4테마 전부 렌더해야 검사 통과(병렬로 돌리면 빠름). 렌더 1편 ≈ 3분.
4. **소리**: `node tools/make-bgm.mjs`(배경음악 합성), 내레이션은 `references/audio-deploy.md`.
5. `style.css`를 고쳤으면 **반드시** `python3 tools/make-themes.py` (기본 테마 noir는 themes/noir.css를 쓰므로 안 하면 반영 안 됨).
6. **검사**: `node tools/check.mjs` → "✔ 모두 통과"여야 커밋. 장면 수가 바뀌면 check.mjs의 장면 번호(#n) 기대값을 같이 고친다.
7. **눈으로 확인**: Playwright로 해당 장면 캡처해서 직접 본다(`?nostart#장면번호` 로 시작 버튼 건너뜀). 데스크톱 1440×860 + 휴대폰 가로/세로.
8. 커밋·푸시 → Vercel 배포(`references/audio-deploy.md`의 정확한 호출) → `get_deployment`로 READY와 별칭 확인 → 사용자에게 주소와 바뀐 점 보고.

## 사용자가 원하는 모습 (지난 피드백에서 나온 규칙 — 꼭 지킬 것)
`references/lessons.md`에 이유와 함께 정리. 요약:
- 하단 조작 막대·좌측 번호 레일 없음. 조작은 단축키 + 화면 밖 아래쪽의 작은 단축키 안내 + 큰 "전체 화면" 버튼.
- 첫 화면은 "▶ 발표 시작" 버튼(브라우저가 소리를 막으므로 필수). 누르면 1부→2부→3부→감사 장면까지 **멈춤 없이 자동 진행**.
- 뻔한 "왼쪽 이미지·오른쪽 글" 반복 금지. 이미지는 크게 등장했다가 칸으로 들어오고, 클릭하면 확대. 부 표지는 큰 글씨가 한 글자씩 생성(CF 느낌).
- 텍스트만 있는 장면 금지 → 비슷한 제품 시연 영상처럼 보여 준다. 설명은 짧게.
- SNS 자동화 시연은 실제 인스타그램 게시물·피드·블로그 글 모양으로.
- 수치·문구는 근거 문서에서 그대로, 출처를 장면 아래에 표기. 시안 사이트를 인용할 땐 본문 문장 그대로 따옴표.
- "참고 예시"는 솔루션 제안처럼 말하지 않는다(배지·표지·내레이션 모두).
- 배경음악은 재생 중에만, 일시정지·마지막 장면 뒤엔 꺼짐. 경쾌한 곡 선호, 칩튠·신스 금관 소리는 "이상하다"는 평.
- 늘어지면 안 됨: 1.25배속, 내레이션 끝나고 0.6초 뒤 다음 장면.
- 시연 영상은 클릭하면 화면 가득, 다시 클릭하면 원래대로.
- 결과물 상단에 제작사 이름("Dr.GEO × CoMindWorks" 등) 넣지 말 것 — 고객 이름 + "제안서".

## 막히는 지점
- 네트워크: 이 클라우드 환경은 외부 사이트(고객 홈페이지, api.typecast.ai 등)가 막혀 있을 수 있다. Vercel에 올라간 사이트는 `mcp__Vercel__web_fetch_vercel_url`로 읽힌다.
- 검사 브라우저(Playwright Chromium)는 H.264·AAC를 못 튼다. 영상 재생 검사는 check.mjs가 VP9 임시 사본으로 하고, 배경음악은 볼륨 변화로만 확인한다.
- `pgrep -f`로 프로세스를 죽이지 말 것(세션 자체가 죽은 적 있음). 렌더 백그라운드 작업은 로그 파일로 확인.
